# Capri 0.2.0

Второй релиз форка Libes6 на основе изменений dev до ee1f97d.

## Новое

- Отдельное окно настроек с сохранением, синхронизацией с меню и оформлением в стиле Cyberpunk.
- Автоматический выбор языка системы с английским fallback; общие тексты больше не привязаны к Windows.
- Доступность платформенных функций учитывается в меню, настройках и предложениях чата.
- Отслеживание окон на macOS через упакованный Swift helper: сидение на окнах и реакция на их движение.
- Отслеживание окон Linux X11 через EWMH, xprop и xwininfo.
- Настройка инициативы и защита от повторяющихся реплик.
- Более экономная частота перерисовки и приостановка декоративной работы при блокировке/сне системы с сохранением важных событий.
- Проверка, загрузка и установка обновлений из GitHub Releases внутри приложения; состав файлов обновления проверяется перед созданием draft.

## Установщики

- Windows x64: EXE.
- Linux x64: AppImage и DEB.
- macOS Apple Silicon: DMG и ZIP.

## Ограничения

- Полный паритет функций трёх ОС не заявлен. Доступные возможности зависят от платформы, окружения и разрешений.
- Native Wayland не поддерживается. Linux watcher работает в X11; в XWayland отслеживание чужих окон отключено.
- Windows signing и Apple Developer ID/notarization не настроены. Эти сборки не имеют доверенной подписи распространения.
- Реальное обновление Windows NSIS/Linux AppImage и работа на всех вариантах desktop не подтверждаются одной лишь сборкой в CI.
- Версия 0.1.0 не содержит встроенного updater: первое обновление с 0.1.0 нужно установить вручную.

Релиз подготовлен как draft. Для проверки файлов прилагается SHA256SUMS.txt. Публикация отдельно делает эту версию видимой установленным копиям с поддержкой обновлений.
